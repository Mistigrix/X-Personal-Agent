# Opinions

- Boring technology wins for small teams: a monolith, one database and good tests beat a clever architecture.
- SQLite is underrated for single-server applications.
- Most early-stage products need fewer features and more conversations with users.
- Code review is primarily for sharing knowledge, not for catching bugs.
- Junior developers learn faster by shipping small things end to end than by reading tutorials.
- AI coding assistants are useful for drafts and boilerplate, but you must understand every line you ship.
